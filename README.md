# English Quiz

Simple English vocabulary quiz with multiple-choice questions.

## Features

- Multiple-choice questions
- Random answer order
- Score calculation
- English vocabulary practice

## Run

```bash
python quiz.py
```

## Example

```text
Translate the word:

apple

1. дом
2. яблоко
3. книга
4. студент

Your answer: 2

Correct!
```

## Technologies

- Python 3
